# NOVA AI

Современный landing page для AI SaaS-продукта в технологичной dark-тематике.

## Возможности

- Адаптивная вёрстка
- Dark UI
- Анимации и интерактивные элементы
- Адаптация под desktop и mobile
- Чистая HTML / CSS / JavaScript структура
- Без UI-фреймворков

## Стек

- HTML5
- CSS3
- JavaScript
